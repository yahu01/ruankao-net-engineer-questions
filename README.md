# 软考网络工程师历年真题数据集（2019-2023）+ 近年真题精析（2024-2026）

结构化的软考中级「网络工程师」上午题真题数据集，JSON Lines 格式，共 **480 题**，每题含题干、四个选项、参考答案与解析。适用于刷题应用开发、LLM 微调/评测、备考研究。

## 数据构成

| 文件 | 题数 | 说明 |
|---|---|---|
| `data/neteng_2019_2023.jsonl` | 453 | 2019-2023 年上午综合知识真题（8 个考季） |
| `data/neteng_2024_2026_recalled.jsonl` | 27 | 2024-2026 机考回忆版精选（带详细考点解析） |

## 字段说明

```json
{
  "id": "menu-rknet-2022上半-01-015",   // 唯一 ID（含年份与卷次）
  "paper": "menu-rknet-2022上半-01",    // 所属试卷
  "no": 15,                              // 题号
  "question": "题干文本……",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": "B",                         // 参考答案（单选 A-D）
  "analysis": "解析文本（部分年份为空）",
  "year": "2022年上半年真题"
}
```

## 质量说明（QA 规则）

- 全部为单选题，四个选项无重复（大小写不敏感校验）
- 剔除了依赖配图的题目（原图无法随文本数据分发）
- 剔除了 OCR/文本提取造成的选项错配题
- 2023 年 11 月起软考改为机考，本数据集的 2023 年 5 月卷为纸考末代真题；2024-2026 为社区回忆版精选

## 数据来源与许可

- 2019-2023 真题：整理自开源备考仓库 [xiaomabenten/network_engineer](https://github.com/xiaomabenten/network_engineer)（**Apache-2.0 License**）的 PDF 真题文本层，经结构化加工与质量过滤
- 2024-2026 回忆版：来自 [GUIDchen/ruankao-network-engineer](https://github.com/GUIDchen/ruankao-network-engineer)（**MIT License**）
- 本仓库的二次加工部分（结构化、清洗、QA 过滤）同样以 **Apache-2.0** 发布

> 部分年份（2011-2018）因原始 PDF 为双栏扫描排版，文本提取质量不达标，为保证数据可靠性未收录。

## 在线刷题

本数据集已做成免费刷题微信小程序 **「万题通关」**（微信搜索即可），支持章节练习、模拟考试、错题本、答题排行，另收录软考架构师/高项/软设、考研英语、四六级词汇、驾考、公考行测等 8 个科目共 5 万余题。
